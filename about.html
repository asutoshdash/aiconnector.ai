Our editorial approach

Clear sources. Visible limitations.

We aim to help you make informed decisions. A listing is a starting point for your own evaluation.

01

Start with official documentation

Directory descriptions summarize provider documentation and link to official sources. Inclusion does not imply hands-on testing or a security certification.

02

Explain the trade-offs

We describe intended uses, setup requirements, and limitations. Confirm current pricing, availability, permissions, and data handling with the provider.

03

Make commercial relationships clear

There are currently no paid placements or affiliate links. Future sponsored placements will be labeled and kept separate from editorial comparisons.

04

Welcome corrections

Tools change. If a listing is incomplete or out of date, send us the relevant official source so we can review it.
